# Flutter Menu

App Flutter con menú inferior (`BottomNavigationBar`) de **Personas**, **Chats** y **Llamadas**, con estilo *liquid glass* y datos simulados en memoria.

- **Personas**: contactos agrupados por inicial, búsqueda, filtro "En línea" y perfil con acciones (mensaje, llamada, videollamada).
- **Chats**: conversaciones con no leídos, búsqueda, nuevo chat, deslizar para eliminar y respuestas simuladas ("escribiendo…").
- **Llamadas**: historial (entrantes, salientes, perdidas), filtro de perdidas, llamada simulada con reloj y registro automático.

```
flutter pub get
flutter run
flutter test
```
